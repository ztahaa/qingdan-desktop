Qingdan portable local web edition
==================================

1. Copy the entire Qingdan folder to D:\Qingdan.
2. Double-click start-Qingdan.bat.
3. The app opens in your default browser.
4. Keep the minimized PowerShell window open while using the app.
5. Double-click stop-Qingdan.bat to stop the local service.

No GitHub, Rust, Node.js, administrator rights, or network connection is required.
All task data is stored in D:\Qingdan\data\state.json.
