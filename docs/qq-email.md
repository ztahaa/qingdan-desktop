# QQ 邮箱提醒使用步骤

1. 在自己的电脑浏览器打开 https://mail.qq.com 并登录。
2. 在设置中查找“账号”或“账号与安全”，找到 POP3/IMAP/SMTP 服务，开启 SMTP 相关服务，按页面要求完成身份验证并生成授权码。界面名称可能变化，以 QQ 邮箱当前页面为准。授权码只在你自己的清单设置里填写，不发到聊天或 GitHub。
3. 在清单 v1.2.0 设置中输入自己的完整 `@qq.com` 邮箱和授权码，勾选 QQ 邮箱提醒，点击“保存并发送测试邮件”。不需要填写服务器、端口或购买短信服务。
4. 检查 QQ 邮箱收件箱和垃圾邮件。界面提示“QQ 邮箱已接受”表示 SMTP 受理，不表示手机已经弹出通知。若失败，检查 SMTP 是否开启、授权码是否已过期、网络能否连接 SMTP 端口以及 QQ 邮箱的发送限制。
5. 在手机 QQ 邮箱 App 中登录同一个邮箱，允许 App 通知并检查手机的通知权限、省电和后台设置。手机通知时效取决于邮箱服务、网络和系统设置。
6. 给需要提醒的任务设置截止时间，勾选“截止时邮件提醒”。先创建一项几分钟后到期的测试事项，确认收到提醒后再用于正式事项。

程序通过 `smtp.qq.com:465` 使用加密 SMTP 给同一个 QQ 邮箱发送邮件，不使用短信中转，不要求营业执照。邮件只含事项名称、截止时间，不发送图片、本地目录或授权码。授权码存放在 Windows 凭据管理器，任务数据库、备份和导出均不包含它。更换电脑或 Windows 用户需重新填写。

## 运行与重试

- 只在 Windows 桌面版发送；浏览器预览和便携网页版不发送，也不会把授权码写进浏览器存储。
- 电脑和清单必须保持运行。退出、睡眠、关机或断网时不能保证发送。重开后只处理过去 24 小时内到期、未完成、未删除、主动勾选邮件提醒的事项。
- 每 30 秒处理一项到期提醒；大量任务同时到期时会排队。
- 同一任务、截止时间、邮箱的已受理提醒在本地记录中去重。SMTP 明确临时拒绝时最多自动尝试三次；明确失败可在修复配置后点击“重试失败提醒”。
- 超时、连接中断和发送期间程序退出，可能发生在服务器已经接收之后。此时记录为“结果不确定”，不会自动重发；先检查邮箱。若确实需要再发，可调整该任务截止时间，产生新的提醒。
- 已经开始发送的邮件无法撤回；将任务完成或放回收站只阻止尚未开始的后续提醒。恢复更早备份可能丢失之后的发送记录，可能重新产生提醒。
- 删除授权码会关闭此应用的邮件提醒，但不会自动在 QQ 邮箱服务端吊销授权码；需完全吊销时在 QQ 邮箱管理页操作。

## 一键导出

点击页面右上角“一键导出事项”，选择保存位置，得到包含未完成和已完成事项的 CSV；默认排除回收站。下拉选项可导出当前列表（当前分类/搜索/回收站的结果），或完整事项 JSON（包含图片）。CSV 的时间保留 ISO 时区值，文本按 CSV 规则转义并防止公式执行；JSON 用于保留原始数据。本次不提供 JSON 导入界面。
